Scopul aplicației: Facilitarea cumpărării mobilierului prin intermediul unei platforme digitale. Utilizatorii vor avea posibilitate să vizualizeze produse disponibile, să caute, să consulte prețurile și să adauge rpodusele dorite într-un coș de cumpărături.
Membrii echipei: Tincu Diana

Structura proiectului: 
READ.ME - conține informații generale despre proiect.
DOCS - conține documentația proiectului, analiza cerințelor și descrierea funcționării.
SCREENSHOTS - conține capturi de ecran ale interfeței aplicației, precum pagina principală, catalogul de produse, de căutare, coșul de produse, pagina indiviuală a produselor și accountul utilizatorului.
DESIGN - conține schițele interfeței, paleta de culori și elemente grafice utilizate.
PROTOTYPE - conține prototipul din figma.
